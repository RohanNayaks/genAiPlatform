ARCHITECTURE OVERVIEW:

User Input
   ↓
FastAPI Endpoint (/getResponse)
   ↓
Intent Detection (keyword: "generate")
   ↓
Cache Check (Redis)
   ├→ Cache Hit: Return cached response
   └→ Cache Miss: ↓
      InputGuardial (Entity Masking)
         ↓
      TemplateCreator (Prompt Template)
         ↓
      InvokeGenAI (Model Execution)
         ├→ Phi3 Model
         └→ OpenAI Model
         ↓
      Cache Store & Return Response
